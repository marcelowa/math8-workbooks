# חוברות מתמטיקה · כיתה ח׳

**האתר החי:** https://marcelowa.github.io/math8-workbooks/

שבע חוברות עבודה להדפסה במתמטיקה לכיתה ח׳ — הסבר, דוגמה פתורה, מלכודות ותרגול לפי טכניקה.

## איך פותחים

אין התקנה ואין שרת.

1. חלצו את קובץ ה־ZIP לתיקייה במחשב.
2. פתחו את `index.html` בדפדפן (Chrome, Edge או Safari).
3. אם הדפדפן שואל — אשרו פתיחת קובץ מקומי.

זה הכול. הפונט נטען מ־Google Fonts; בלי אינטרנט הדפדפן עובר לפונט מערכת, והחוברות עדיין עובדות.

## איך מדפיסים

1. פותחים חוברת ולוחצים **הדפסה** (או `Ctrl/Cmd + P`).
2. בוחרים **A4**, קנה מידה **100%**, שוליים **ברירת מחדל**.
3. מפעילים **גרפיקה ברקע** — אחרת הצבעים והשרטוטים לא יודפסו.
4. אפשר דו־צדדי. נספח התשובות בסוף כל חוברת, אחרי קו קריעה.

## מה בכל עמוד טכניקה

1. **הכלל** — הנוסחה או המשפט.
2. **למה זה עובד** — ההסבר, לא רק השינון.
3. **דוגמה פתורה** — שלבים ממוספרים.
4. **מלכודת** — הטעות הנפוצה לפני שהיא קורית.
5. **תרגול** — 6–9 תרגילים שמתאימים לאותה טכניקה.
6. **סיימתי** — סימון שנשמר בדפדפן.

## מה לא כלול

- פונקציה קווית, סטטיסטיקה והסתברות — עדיין לא בחוברות. אפשר להוסיף בהמשך.

## איך לערוך

- צבע החוברת: המשתנה `--accent` בתגית `body` בכל קובץ.
- תוכן: כל טכניקה היא `<section class="sheet tech">`; תרגילים הם `<li>` בתוך `<ol class="ex">`.
- תשובות: `<section class="sheet answers">` בסוף הקובץ.
- עיצוב משותף: `assets/base.css` ו־`assets/booklet.css`.
