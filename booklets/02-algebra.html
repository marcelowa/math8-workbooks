אלגברה
ביטויים ומשוואות

מלשון בני אדם למשוואה, ומשם לפתרון. לא מנחשים — פותחים סוגריים, מכנסים איברים, ומגיעים ל־x לבד באגף אחד.

אלגברה היא שפה

אות היא לא "משהו מסתורי" — היא קיצור למספר שלא ידוע עדיין. כל ביטוי אפשר לתרגם לעברית, וכל משפט אפשר לתרגם לביטוי. ברגע שיש תרגום, הפתרון הוא שורת כללים.

ארבעה צעדים בכל תרגיל

1 · קוראיםמה נתון, ומה מבקשים? מסמנים את הנעלם באות.
2 · מפשטיםפותחים סוגריים ומכנסים איברים בכל אגף בנפרד.
3 · מבודדיםמעבירים משתנים לאגף אחד ומספרים לשני — בפעולה הפוכה.
4 · בודקיםמציבים את הפתרון במשוואה המקורית. אם שני האגפים שווים — נכון.

שלוש החלטות שמונעות טעויות

סימן לפני סוגרייםמינוס לפני סוגריים הופך כל סימן בפנים: -(x-4) = -x+4.
שורה אחת = פעולה אחתלא מנסים לעשות הכול בראש. כל מעבר נכתב מתחת לקודם.
כמו מאזנייםמשוואה היא מאזניים: מה שעושים לאגף אחד — עושים גם לשני.
איך יודעים שהצלחת לא לפי "נראה לי שהבנתי", אלא לפי הצבה חוזרת שנותנת שוויון אמיתי — ועל הדרך גם מגלה טעמי סימן.

מלשון לביטוי

בסוף הקטע: תדע לתרגם משפט בעברית לביטוי אלגברי, ולזהות מקדם ומשתנה.

הכלל

המשמעות של 3x:  3 · x

משתנה — האות (x). מקדם — המספר שמוכפל באות (3). ביטוי — צירוף של מספרים, משתנים ופעולות, בלי סימן שוויון.

טכניקה

כינוס איברים דומים

בסוף הקטע: תדע לקצר ביטוי ארוך לשורה אחת, בלי לאבד איברים ובלי לחבר דברים שאינם דומים.

הכלל

3x + 5x = 8x   |   4x2 + 2x2 = 6x2

איברים דומים = אותו משתנה באותה חזקה. מחברים את המקדמים ומשאירים את המשתנה כמו שהוא.

למה זה עובד

3x + 5x הוא שלושה עותקים של x ועוד חמישה עותקים — בסך הכול שמונה עותקים: 8x. זה בדיוק כמו 3 תפוחים + 5 תפוחים = 8 תפוחים.

דוגמהמסדרים לפי חזקה
  1. 5x + 2x2 - 3x
  2. מסמנים דומים: 5x - 3x = 2x, ו־2x2 נשאר לבד
  3. = 2x2 + 2x
מלכודת

x + x = 2x, לא x2. וגם 3x + 2y נשאר כמו שהוא — אין דרך לכנס משתנים שונים.

טכניקה

פתיחת סוגריים

בסוף הקטע: תפתח סוגריים עם מספר לפני הסוגריים — כולל מינוס — בלי להפיל סימנים.

הכלל

a(b + c) = ab + ac

המספר שלפני הסוגריים מוכפל בכל איבר בפנים. אם לפני הסוגריים יש מינוס — הוא הופך את הסימן של כל איבר.

דוגמהחיובי
  1. 3(2x - 5)
  2. = 3·2x - 3·5
  3. = 6x - 15
דוגמהשלילי
  1. -2(3x - 1)
  2. = -2·3x + 2·1
  3. = -6x + 2
מלכודת

כשמינוס לפני סוגריים, הוא נוגע בשני האיברים: -(x - 4) = -x + 4, ולא -x - 4. שווה לכתוב ביניים: -1·x + (-1)·(-4).

טכניקה

כפל מקוצר

בסוף הקטע: תפתח ריבוע של סכום, ריבוע של הפרש והפרש ריבועים — בלי לכפול כל איבר בכל איבר בכל פעם.

שלוש הנוסחאות

(a + b)2 = a2 + 2ab + b2
(a - b)2 = a2 - 2ab + b2
(a + b)(a - b) = a2 - b2

בשני הריבועים תמיד יש שלושה איברים. בהפרש ריבועים — שניים, והאמצעי נעלם.

דוגמהשלושה מקרים
  1. (x + 3)2 = x2 + 2·x·3 + 32 = x2 + 6x + 9
  2. (2x - 5)2 = 4x2 - 20x + 25
  3. (3a + 4)(3a - 4) = 9a2 - 16
מלכודת

(x + 3)2 ≠ x2 + 9. חסר האיבר האמצעי 6x — והוא בדיוק החלק שמופיע פעמיים בריבוע. בדיקה מהירה: הציבו x = 1; (1+3)2 = 16, אבל 1+9 = 10.

טכניקה

פירוק לגורמים

בסוף הקטע: תהפוך סכום למכפלה — גורם משותף, הפרש ריבועים וריבוע שלם.

הכלל

ab + ac = a(b + c)
a2 - b2 = (a - b)(a + b)

פירוק הוא הפעולה ההפוכה לפתיחת סוגריים. תמיד בודקים קודם אם יש גורם משותף לכל האיברים.

דוגמהגורם משותף
  1. 6x2 + 9x
  2. הגורם המשותף: 3x
  3. = 3x(2x + 3)
דוגמההפרש ריבועים
  1. x2 - 25
  2. = x2 - 52
  3. = (x - 5)(x + 5)
איך מזהים

הפרש ריבועים: שני איברים, שניהם ריבועים, וביניהם מינוס. ריבוע שלם: שלושה איברים, והראשון והאחרון ריבועים. גורם משותף: אותו גורם מופיע בכל האיברים.

מלכודת

x2 - 25 ≠ (x - 5)2. (x-5)2 שווה x2 - 10x + 25. הפרש ריבועים נותן מכפלה של שני גורמים, לא ריבוע.

משוואה — כמו מאזניים

בסוף הקטע: תפתור משוואה לינארית עם סוגריים, ותבדוק את הפתרון בהצבה.

הכלל

אגף שמאל = אגף ימין, ולכן x = ?

מעבירים איבר מאגף לאגף בפעולה ההפוכה: פלוס הופך למינוס, כפל הופך לחילוק. המטרה: x לבד באגף אחד.

דוגמהעם בדיקה
  1. 3x + 5 = 7x - 11
  2. 5 + 11 = 7x - 3x — מעבירים אגפים
  3. 16 = 4x
  4. x = 4
  5. בדיקה: 3·4+5 = 17 וגם 7·4-11 = 17 ✓
מלכודת

כשמעבירים איבר אגף — הסימן מתהפך: 3x + 5 = 20 הופך ל־3x = 20 - 5. טעות נפוצה: להעביר בלי להפוך, ואז לקבל פתרון הפוך.

  2. 3x - 5 = 10
  3. 4x + 3 = 2x + 11
  4. 5(x - 2) = 20
  5. 2(x + 3) = 3x - 1
  6. 3x - 4 = 7x + 8
  7. x/3 + 2 = 5
  8. (x + 1)/2 = 4

טכניקה

משוואות עם שברים ועשרוניים

בסוף הקטע: תפתור משוואה עם שברים או עשרוניים בלי להסתבך, ותדע לזהות מתי אין פתרון.

הכלל

כפלו את שני האגפים במכנה המשותף

ככה נעלמים השברים, והמשוואה הופכת למשוואה רגילה. עם עשרוניים — כופלים ב־10 או ב־100 לפי מספר הספרות אחרי הנקודה.

דוגמהשברים
  1. x/2 + x/3 = 5
  2. מכנה משותף 6: 3x + 2x = 30
  3. 5x = 30
  4. x = 6 בדיקה: 6/2 + 6/3 = 3 + 2 = 5 ✓
מתי אין פתרון

אם אחרי הפישוט מקבלים משהו כמו 3 = 5 — אין פתרון. אם מקבלים 0 = 0 — כל מספר הוא פתרון.

טכניקה

בעיות מילוליות

בסוף הקטע: תדע להפוך סיפור למשוואה — לבחור מה הנעלם, לתרגם כל משפט, ולבדוק שהתשובה הגיונית.

ארבעה צעדים

הגדרה → תרגום → פתרון → בדיקה

הגדרה: "יהי x הגיל של…". תרגום: כל משפט הופך לביטוי. פתרון: פותרים משוואה. בדיקה: מציבים בסיפור, לא רק במשוואה.

דוגמהגילים
  1. אבא מבוגר פי 3 מהבן. סכום הגילים 48. מה הגיל של כל אחד?
  2. נסמן: גיל הבן x, גיל האבא 3x
  3. x + 3x = 48 → 4x = 48 → x = 12
  4. הבן בן 12, האבא בן 36. בדיקה: 12 + 36 = 48 ✓
מלכודת

"פי 3" הוא 3x, ו"גדול ב־3" הוא x+3. קראו את המשפט פעמיים לפני שכותבים. בסוף — ענו במילים: "הבן בן 12", לא רק "x=12".

טכניקה

בידוד משתנה בנוסחה

בסוף הקטע: תדע לקחת נוסחה כמו P = 2(a+b) ולבודד ממנה כל משתנה — לא רק את זה שבאגף שמאל.

הכלל

אותה משוואה, פשוט עם אותיות

כל פעולה שמותר לעשות במשוואה — מותרת גם בנוסחה. מבצעים את הפעולות ההפוכות לפי הסדר, מהחיצוני לפנימי.

דוגמהמההיקף לרוחב
  1. P = 2(a + b)
  2. מחלקים ב־2: P/2 = a + b
  3. מחסרים b: P/2 - b = a
  4. a = P/2 - b
מלכודת

כשמחלקים ב־2, מתחלק כל האגף — לא רק האיבר הראשון. P = 2a + b לא הופך ל־P/2 = a + b; הוא הופך ל־P/2 = a + b/2.

  2. A = b·h בודדו h
  3. v = u + at בודדו a
  4. C = 2πr בודדו r
  5. S = v·t בודדו t
  6. F = m·a בודדו m

טכניקה

אי־שוויונות

בסוף הקטע: תפתור אי־שוויון כמו משוואה, ותדע מתי הסימן מתהפך.

הכלל

כפל או חילוק במספר שלילי — מהפכים את הסימן

כל השאר זהה למשוואה: מעבירים אגפים, מכנסים, מחלקים במקדם. רק כשהמקדם שלילי — < הופך ל־>.

דוגמההסימן מתהפך
  1. -2x < 6
  2. מחלקים ב־-2 — ומהפכים: x > -3
  3. בדיקה: x = 0 נותן 0 < 6 ✓
מלכודת

אם לא מהפכים, מקבלים את הפתרון ההפוך. שימו לב במיוחד כשיש מינוס לפני ה־x — למשל -x > 4 נותן x < -4.

לפני התרגול המסכם

מפת החלטה: מה עושים קודם?

רוב הטעויות באלגברה הן לא בחישוב — הן בבחירת הפעולה. המפה הזאת מסדרת את הסדר.

יש סוגרייםפותחים לפני הכול, או מפרקים אם מבקשים מכפלה.
יש שבריםכופלים את שני האגפים במכנה המשותף.
x בשני האגפיםמעבירים את כל ה־x לאגף אחד ואת המספרים לשני — עם היפוך סימן.
מבקשים לפרקקודם גורם משותף, אחר כך הפרש ריבועים או ריבוע שלם.
יש אי־שוויוןפותרים כמו משוואה; מהפכים רק בכפל/חילוק בשלילי.
סיימתמציבים בחזרה. תמיד.

חמש הטעויות שעולות הכי הרבה נקודות

1 · מינוס לפני סוגריים-(x-4) = -x+4. המינוס נוגע בשני האיברים.
2 · האיבר האמצעי(x+3)2 = x2+6x+9, לא x2+9.
3 · x ועוד xx+x = 2x, לא x2. חזקה היא כפל, לא חיבור.
4 · העברת אגףהסימן מתהפך כשעוברים אגף. 3x+5=20 → 3x=15.
5 · חלוקה חלקיתכשמחלקים אגף — מחלקים כל איבר בו.
